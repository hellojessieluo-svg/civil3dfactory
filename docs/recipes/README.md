# Recipes

Field-tested ways of working, written as checklists with a measurable "done means". Each page names the ops and
tools it uses; parameters are derived from the drawing, never guessed.

| Page | Covers |
|---|---|
| [sheet-sets.md](sheet-sets.md) | Re-plot a set after title block edits, reproduce a set a client already has, check a sheet catalogue against the drawings, swap a whole title block, extract a demo title block. Tool: [tools/sheet-set](../../tools/sheet-set/README.md). |
| [incoming-drawings.md](incoming-drawings.md) | Keep only what lies inside a boundary, fix broken text styles, convert plan text to annotative. |
| [lines-and-labels.md](lines-and-labels.md) | Collect elevated design lines from many drawings, turn a centre-line network into alignments with fillets, coordinate labels. |
| [terrain-and-earthwork.md](terrain-and-earthwork.md) | Grid earthwork balance, estimated post-dredge terrain without an as-built survey, overlaying drawing geometry with surveyed points. |
